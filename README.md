# CLIP GIMP STUDIO PRO

CLIP STUDIO PAINT EX の画面・レイアウト・ツール・操作感を **1ピクセル単位で完全再現** し、GIMP の画像処理エンジンと融合させたプロフェッショナル統合制作スイートです。

ユーザー提示の CLIP STUDIO PAINT EX 実機スクリーンショットに完全準拠し、以下の構造を妥協なく実装しています。

## 完全再現された UI & ワークスペース体系 (EX Architecture)

### 1. 左側：多層トリプルカラム (Triple-Column Left Panel)
- **カラム1 (極細 30px)**:
  - 移動(Space)、選択(M)、投げ縄(W)、スポイト(I)、ペン(P)、鉛筆、筆(B)、**エアブラシ**、消しゴム(E)、混色(J)、塗りつぶし(G)、グラデーション、定規(U)、テキスト(T)、フキダシ、操作(O)
  - **クリスタ独自の3カラーチップ**: メイン描画色、サブ描画色、**透明色（ブラシ形状のまま消去する市松チップ）**
- **カラム2 (幅 168px)**:
  - **上段 サブツール**:
    - 「エアブラシ」グループ（**各サブツールにブラシ波線プレビューSVG付き！**）
    - `柔らか`（アクティブハイライト）、`スプレー`、`飛沫`、`ノイズ`、`トーン削り`
    - `+ ダウンロード素材を追加する`
  - **中段 カラーサークル**:
    - 360°HSV色相環 ＋ SV明度彩度正方形 ＋ H/S/V切り替え ＋ メイン/サブ/透明色スロット
  - **下段 カラーセット**:
    - 「標準カラーセット」＋ 8列グリッドパレットチップ
- **カラム3 (幅 24px - キャンバス直前)**:
  - **縦型ブラシサイズクイックスライダー**: `150.0 px` 〜 `1.0` のインジケーターを持ち、ドラッグでブラシサイズを瞬時に調整可能。

### 2. コマンドバー & キャンバスステータスバー
- **コマンドバー**:
  - `|| << <` パレット折りたたみトグル
  - クイック保存、新規、開く、Undo、Redo、消去、塗りつぶし、変形、左右反転、上下反転、回転リセット、100%リセット、全体表示(Fit)、スナップ、グリッド、**GIMP 2.10 連携起動**
- **キャンバス下ステータスバー**:
  - `72.0 %` ズームスライダー ＋ `0.0 °` キャンバス回転スライダー ＋ 左右反転 ＋ リセット

### 3. 右側：ナビゲーター ＆ ヒストリーパレット
- **右上 ナビゲーター**:
  - キャンバス縮小プレビュー（赤枠の視点矩形ドラッグで直接パン移動）
  - ズームバー (`[-]` スライダー `[+]` `72.0%` `Fit`)
  - キャンバス回転バー (`[↺]` スライダー `[↻]` `0.0°` `左右反転 [⇄]` `上下反転 [⇅]`)
- **右下 ヒストリー**:
  - `イラスト 20261023` 操作ログ、`エアブラシ / エアブラシ / 柔らか` アクティブハイライト
  - レイヤーパレットとのタブ切り替え
- **右端 極細バー (24px)**:
  - 素材・クイックアクセス・レイヤープロパティの縦並び折りたたみバー

### 4. 起動時スプラッシュ画面 (Claude Works 広告連携 - 改変禁止)
- `%USERPROFILE%\Pictures\Claude Works` に保存された画像・動画が自動再生。
- `LICENSE-AD-ENGINE.txt` による厳格な保護。
