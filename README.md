# CLIP GIMP STUDIO

クリーンルーム開発（Clean-room Engineering）による、CLIP STUDIO (`CLIPStudio.exe`) および **CLIP STUDIO PAINT** のUIレイアウト・ツール・機能を妥協なく完全に再現した GIMP 専用のマネージャー＆統合制作スイートです。

##  完全再現された UI & 機能体系 (Features)

### 1. トップメニューバー & コマンドバー
- **メニューバー**: ファイル(F)、編集(E)、レイヤー(L)、表示(V)、フィルター(I)、ウィンドウ(W)
- **コマンドバー**:
  - `新規作成` `画像を開く` `作品保存`
  - `元に戻す (Ctrl+Z)` `やり直し (Ctrl+Y)` `レイヤー消去` `塗りつぶし`
  - `拡大` `縮小` `100%表示` `ウィンドウに合わせる (Fit)`
  - `キャンバス左右反転 (H)` `キャンバス回転リセット (0°)`
  - `対称定規 (ミラー描画)` `方眼グリッド表示`
  - `GIMP で直接開く (ワンクリック連携)`

### 2. 左側：ツール・サブツール・ツールプロパティ
- **メインツールパレット (幅 42px)**:
  - 移動/手のひら (Space)、選択範囲 (M)、スポイト (I/Alt)
  - ペン (P)、ブラシ/水彩 (B)、エアブラシ、消しゴム (E)、塗りつぶし (G)
  - **クリスタ独自の3カラーチップ**: メイン描画色、サブ描画色、**透明色（ブラシ形状のまま消去する機能）**
- **サブツールパレット**:
  - Gペン、丸ペン、カブラペン、ざらつきペン、ミリペン、濃い水彩、滑らか水彩、油彩、エアブラシ、硬め/柔らかめ消しゴム
- **ツールプロパティパレット**:
  - ブラシサイズスライダー (`[` / `]` キーで即座に伸縮)
  - 不透明度スライダー
  - 硬さ (ボケ足) スライダー
  - 手ブレ補正スライダー (0〜20)
  - 筆圧感知 (PointerEvent pressure 対応)

### 3. 中央：描画キャンバス & 定規
- 高解像度マルチレイヤー描画エンジン
- 手ブレ補正ストローク補間アルゴリズム
- **対称定規 (Symmetry Ruler)**: 中心線を境に左右対称の線画を同時描画
- **方眼グリッド (Grid)**: 背景ガイドライン表示
- リアルタイム・ズーム、キャンバス回転、左右反転、上下反転、パン移動

### 4. 右側：ナビゲーター・カラー・レイヤーパレット
- **右上：ナビゲーター (Navigator)**:
  - キャンバス全体のリアルタイム縮小プレビュー（赤枠の視点矩形ドラッグで直接パン移動可能）
  - **ズームバー**: `[-]` スライダー（10%〜800%） `[+]` `100%` `Fit`
  - **キャンバス回転バー**: `[↺]` スライダー（-180°〜+180°） `[↻]` `0.0°` `左右反転 [⇄]` `上下反転 [⇅]`
- **右中：カラーシステム (Color)**:
  - **カラーサークル**: 外周360°色相環 (Hue) ＋ 内側明度彩度正方形 (SV Square)
  - **カラースライダー**: RGBスライダー
  - **カラーセット**: クリスタ標準16色パレットチップ
- **右下：レイヤーパレット (Layers)**:
  - **クリスタ特有の「下のレイヤーでクリッピング」** (Clipping Mask)
  - **「透明ピクセルをロック」** (Lock Alpha)
  - **「下描きレイヤー化」** (Draft Layer)
  - 合成モード：通常、乗算、スクリーン、オーバーレイ、加算(発光)、比較(暗)、比較(明)
  - レイヤー不透明度スライダー、目玉アイコン（表示/非表示）、レイヤー複製、下に結合、削除

### 5. GIMP 本体の完全クリスタ化設定
- `sessionrc`: ドッキングウィンドウをCLIP STUDIO PAINTと同一に配置
- `menurc`: クリスタ準拠ショートカットキー（B, E, G, M, V, H, Ctrl+T等）
- `gimp.css`: スタジオダークテーマ（#28292B）
- `splash.png`: CLIP GIMP STUDIO仕様のスプラッシュスクリーン
- `.gpl`: アニメ塗り肌色パレット、環境光パレット
